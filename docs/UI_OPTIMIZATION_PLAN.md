# Game-Agent 前端界面优化方案

> 现状：桌面骨架（菜单栏/侧栏/内容簇/组件栏/Dock/窗口）、开屏锁屏、四主题已完成。
> 本方案把这些从「复刻Demo」推进到「有产品感的操作系统」，按 P0（立刻做）/ P1（下一步）/ P2（锦上添花）分级。
> 每项标注：现状问题 → 方案 → 涉及文件 → 预估工作量。

---

## P0 · 立刻做（合计约 3–4 天，全是高感知低成本项）

### P0-1 动效系统：让界面「活」起来 ⭐ 优先级最高

**现状**：除了窗口 pop 动画和悬停缩放，整个桌面是静态的；原站的「操作系统感」一半来自动效。

| 动效 | 规格 | 文件 |
|---|---|---|
| 解锁入场序列 | 锁屏退场后，桌面元素 stagger 入场：菜单栏下滑淡入(0ms) → 内容簇上浮淡入(80ms) → 图标逐个弹入(120ms+i×40ms, spring) → 组件栏右侧滑入(200ms) → Dock 上浮(260ms) | `Desktop.tsx` 新增 `PhaseGate` 包裹 + CSS 变量 `--stagger-delay` |
| Dock 放大镜 | 鼠标靠近时图标按高斯距离放大 1→1.5，邻居半程衰减；离开回弹。纯 transform 实现 | `Dock.tsx`（监听 mousemove 算距离，~40 行） |
| 图标浮起 | hover: translateY(-3px) + 阴影从 `0 10px 24px` → `0 18px 32px`；active: scale(.94) | `DesktopIcons.tsx` |
| 窗口最小化 | 点黄色灯 → 窗口缩放飞向 Dock 对应图标位置（FLIP 动画），Dock 图标跳动一下 | `GameWindow.tsx` + `Dock.tsx`（需先有 P1-1 窗口管理器） |
| 数字滚动 | 时钟/日期/「4 款游戏待命」数字变化时旧数字上滑新数字入场（每分钟只动一次，成本低感知高） | `MenuBar.tsx` `LockScreen.tsx` |
| 主题切换涟漪 | 点主题圆点时从该点扩散一个圆形高光波纹（600ms，一次性 overlay） | `WidgetPanel.tsx` |

> 全部动效收敛到一个约定：只动 `transform/opacity`，时长 150–500ms，缓动 `cubic-bezier(.2,.9,.3,1.15)`（开窗）与 `ease-out`（退场）；全局监听 `prefers-reduced-motion` 时全部禁用（`globals.css` 一段 media query 即可）。

### P0-2 玻璃与阴影质感统一

**现状**：卡片/菜单栏/Dock 的毛玻璃各自为政，阴影只有一种；和原站相比少了「材质的层次」。

方案（`globals.css` 一次性收敛为三个材质类）：
- `.glass-thin`（菜单栏/侧栏）：blur 20px + `background: color-mix(in srgb, white 30%, transparent)`
- `.glass-card`（组件卡）：保持 blur 18px，增加双层高光——`inset 0 1px 0 rgba(255,255,255,.25)`（顶部受光边）+ `inset 0 0 0 1px rgba(255,255,255,.12)`
- 阴影两级：接触阴影 `0 2px 6px rgba(15,23,42,.10)` + 环境阴影 `0 16px 40px rgba(15,23,42,.12)`，所有浮起元素统一组合使用
- 图标统一「浮起投影」：`0 12px 28px rgba(0,0,0,.30), 0 3px 8px rgba(0,0,0,.18)`，贴原站实物 PNG 的悬浮感

**工作量**：0.5 天，纯 CSS，风险为零。

### P0-3 桌面图标：Squircle + 角标系统

**现状**：`border-radius: 16px` 的圆角方形不够「macOS」；图标无信息量。

- 用 **squircle 超椭圆**替代普通圆角（`clip-path: path(...)` 或内嵌 SVG mask，参考 Figma 的 iOS 圆角连续性），macOS 图标辨识度立刻上来
- 角标预留位（右上角，`-top-1 -right-1`）：红点（有新内容）、数字角标（体力已满/可领取）、小图标角标（版本更新）——数据接入后直接点亮
- 原神当前 App 图标带「6th 周年」角标会过时：给 `games.ts` 加 `icon` 与 `iconFallback` 字段，官方图标换版时只改数据

### P0-4 锁屏增强（半天）

- **实时模糊桌面**：解锁前桌面在锁屏后隐约可见（iOS 锁屏感）。实现：锁屏壁纸层改为 `backdrop-filter: blur(30px)` 的半透明层 + 主题渐变压暗 20%，比「完全遮住」更有系统感
- **时段问候语**：logo 下方按当前时间显示「早上好，旅行者 ✦ / 下午好 / 夜深了，注意休息」（`useNow` 已有，加一个 3 分支函数）
- **开机时壁纸由暗到亮**：boot 阶段给壁纸层加 `brightness(0.6) → 1` 的 2s 过渡，模拟「天亮」，和进度条同步

## P1 · 下一步（合计约 1–1.5 周，交互骨架升级）

### P1-1 真窗口管理器（多窗口 + 最小化 + 最大化）⭐ 架构项

**现状**：`GameWindow` 单实例、位置写死、无 z 栈——这是「操作系统感」的最后一块短板。

- Zustand 建 `windowStore`：`windows: { id, z, pos, size, minimized }[]`、`focus(id)`、`minimize(id)`、`toggleMaximize(id)`
- 标题栏双击最大化（带 200ms 位置过渡）、右下角 resize 手柄、拖到屏幕边缘吸附半屏（可选）
- 失焦窗口标题栏降饱和（`filter: saturate(.4) opacity(.9)`，macOS 行为）
- 最小化：窗口 FLIP 飞向 Dock（配合 P0-1），Dock 图标下方加运行指示点
- `Desktop.tsx` 改为渲染 `windows.map()`，`openGame` 变成 `openWindow(gameId)` 支持多开

**工作量**：2–3 天。做完后「开屏→多窗口办公」的产品故事就完整了。

### P1-2 右键菜单系统（macOS 风格）

- 桌面空白：更换主题（子菜单四色）/ 刷新数据 / 整理图标
- 游戏图标：打开 / 固定到 Dock / 从桌面移除
- 实现：一个 `ContextMenu` 组件 + 全局 `contextmenu` 事件拦截，菜单项配置化。0.5–1 天

### P1-3 组件栏升级：从占位到「活的」

对齐原站组件栏的信息密度，每个卡都变成可交互：

| 组件 | 升级 | 数据依赖 |
|---|---|---|
| 2×2 游戏小卡 | 点击 = 开游戏窗口；角标显示体力满/可签到；长按拖动排序 | 接 API 后点亮角标 |
| Now Playing 大卡 | 对齐原站 Spotify 卡：大封面 + 「正在玩」实时计时 + 「打开启动器 ↗」 | Steam API |
| 本周时长 | 柱状图 hover 出 tooltip（日期+时长）；接入后真实数据 + 环比箭头 | 会话记录 |
| 新增：成就流卡 | 横向滚动最新成就（稀有度描边：金/紫/蓝） | 成就 API |
| 新增：签到月历卡 | 当月日历，已签日期打点，今天可签高亮按钮 | 签到 API |

组件面板加「编辑模式」：右上角进入 → 卡片抖动（iOS 经典）→ 可隐藏/排序 → 完成。纯前端可先做壳。

### P1-4 响应式与触屏降级

- `<lg`（组件栏隐藏时）：菜单栏右侧加「组件」图标按钮，点开从右侧滑出组件抽屉
- 触屏：图标**单击直接打开**（双击太反直觉）、长按代替右键菜单、窗口拖拽已用 Pointer Events 天然支持
- 图标标签在 `md` 以下隐藏，只留图标

### P1-5 快捷键

`Esc` 关窗/关菜单（已有关窗）→ 扩展：`⌘W` 关窗口、`⌘1..4` 打开对应游戏、`⌘K` 命令面板（后续搜索游戏/成就的入口，先做壳）。

## 技术注意（踩过的坑，动效实现时必须遵守）

1. **禁用对「含 backdrop-filter 元素」的 opacity 关键帧动画**（`@keyframes + fill-mode`）——已两次触发合成层冻结/鬼影；用 `transition` 或只动 `transform` 代替
2. 动画只用 `transform/opacity`；宽度类动画已改为 JS 时钟驱动（进度条先例在 `LockScreen.tsx`）
3. 每个新动效在 `prefers-reduced-motion: reduce` 下必须有静态降级
4. 改完跑 `npm run build` + 生产模式验证（dev 的 Turbopack 热更新在本机有死循环前科）
