## 0. 怎么用这份清单

每张 `<Layer>_base.png` 是一张 **407×820 的透明画布**，已经替你摆好了位置：

| 画面元素 | 含义 |
|---|---|
| 目标图层，100% 不透明 | 该部件**现有**的像素，位置不要动 |
| 其余图层，18% 不透明 | 定位参考（上下文），用来对齐 |
| **洋红色区域** | **需要你补画**的地方 |
| **青色虚线框** | 建议补画的包围范围（近似，最终形状由你决定） |
| 左上角文字 | 图层名 + 要补什么 + 坐标范围 |

工作流：在 Photoshop / Clip Studio 打开对应 `_base.png` → 直接照着洋红区画 → **只导出该图层**（其余参考层删掉）→ 覆盖保存回 `assets/live2d/paimon/layers/<Layer>.png`。

总览图：`assets/live2d/paimon/redraw/_overview.png`（13 张缩略图一览）。

## 1. 画布与导出规范（硬性）

- **尺寸固定 407×820**，与源图完全一致；**不裁切、不缩放、不留白边**。
- **RGBA PNG（PNG-24，透明背景）**，每层与源图同坐标，可直接叠加复原。
- **一个部件一个文件**，文件名与 `layers/` 现有文件**完全一致**（大小写敏感）。
- **只做「加画」**：现有像素不得覆盖、移动、重新上色。
- **不要合并图层**，不要输出带背景的图。

## 4. 补画顺序（有依赖，按此顺序做）

1. `Hair_Back` —— 最底层，先定头型轮廓
2. `Face` —— 额头压在 `Hair_Back` 之上，头型定了才好对位
3. `Body` —— 身体主体，决定肩线
4. `Cape_Front` —— 压住身体，需知道身体轮廓
5. `Arm_L` / `Arm_R` —— 压住披风，需知道披风轮廓
6. `Hand_L` / `Hand_R` —— 接在手臂末端
7. `Eye_Closed_*` / `Mouth_Open` / `Brow_*` —— 五官状态，最后画

> 原则：**先底层后上层**。上层部件的补画范围依赖下层的轮廓，顺序颠倒会返工。

## 6. 复现 / 调整底图

```bash
python3 scripts/live2d/make_redraw_templates.py
```

- 输出：`assets/live2d/paimon/redraw/`（13 张底图 + `_overview.png` + `_colors.json`）
- 调整引导范围：改脚本顶部 `TASKS` 里的 `box`（矩形引导）或 `ymax`（头型引导）即可，幂等可重跑。
- 本环境无 Photoshop，故底图为**等价的分层透明 PNG 序列**；如需 `.psd`，用 PS「文件 → 脚本 → 将文件载入堆栈」把 `layers/*.png` 合成即可。
