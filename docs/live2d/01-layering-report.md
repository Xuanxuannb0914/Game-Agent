> 源文件：`public/paimon-pet.png`（407×820，RGBA，透明背景）
> 输出目录：`assets/live2d/paimon/layers/`
> 生成脚本：`scripts/live2d/segment.py`（可重复执行，幂等）

## 1. 结论先行（请务必先读）

自动分层**能可靠拆出「颜色可区分」的部件**，但**不能直接产出可用于 Live2D 建模的图层**。
原因不是工具问题，而是素材本身的性质：

1. **源图是平涂 + 半厚涂的单张 2.5D 立绘**，不是分层稿。头发、披风外层、连衣裙、靴子**全是同一种白色**，只能靠几何位置硬切，切口是直的，不是自然部件轮廓。
2. **被遮挡的区域在原图中根本不存在**。例如刘海盖住额头、披风盖住身体、手臂盖住披风——这些像素从未被绘制，任何自动算法都无法"分割"出不存在的东西，**必须人工补画**。
3. **闭眼 / 张嘴 / 眉毛等状态在原图中不存在**，属于"需要新增绘制"而非"分割"。

因此本次交付定位为：**给建模师一份高质量的「起稿底图」+ 一份明确的「补画清单」**，
而不是假装自动分层已经能直接进 Cubism。

自动分割覆盖率：**169848 / 169882 不透明像素 = 99.98%**
（含线稿归属；重建图 `_rebuild.png` 与源图逐像素一致，分层无损）

## 2. 分层方法与优先级

脚本按「先特异、后整体」的优先级给每个不透明像素分配唯一归属：

| 顺序 | 判定依据 | 说明 |
|---|---|---|
| 1 | **HSV 颜色掩膜** | 金色星饰、蓝色虹膜、肤色（脸/手/腿）、藏青披风内衬——像素级准确 |
| 2 | **几何包围盒** | 把同色的白色区域按位置切分（头发 / 披风 / 裙身 / 靴子 / 手臂） |
| 3 | **线稿归属（Voronoi 生长）** | 深色描边、阴影等无颜色特征的像素，按最近部件归属，随部件一起移动 |

第 3 步很关键：平涂立绘有大量深色描边（睫毛、褶皱、轮廓线），颜色掩膜匹配不到。
若不处理会凭空丢失 10% 像素；处理后会"贴"在所属部件上，这正是 Live2D 需要的行为。

## 4. 必须人工补画的清单（硬性）

以下内容**无法由脚本产出**，请在绘图软件（Photoshop / Clip Studio / Procreate）中补画后，
再导入 Cubism Editor。这是能否建模成功的决定性一步。

### 4.1 补画被遮挡区域（让每个部件成为完整形状）

| 目标图层 | 要补画什么 | 参考 |
|---|---|---|
| `Face` | **额头 + 完整脸部轮廓**（现被刘海覆盖） | 参考左右脸颊走势，补全椭圆脸型 |
| `Hair_Back` | **后脑勺完整头型**（中间现在是脸的空洞） | 补成完整发团，作为头发最底层 |
| `Body` | **连衣裙胸口 + 肩线**（现被披风覆盖） | 沿裙摆褶皱向上补出完整衣身 |
| `Arm_L` / `Arm_R` | **手臂被披风遮住的根部与内侧** | 补出完整上臂，方便做旋转 |
| `Cape_Front` | **披风被手臂压住的部分** | 让披风成为完整一块，可独立摆动 |
| `Hand_L` / `Hand_R` | 手腕与手臂的连接处 | 避免旋转时出现断口 |

### 4.2 需新增绘制（原图不存在的状态）

| 图层 | 说明 |
|---|---|
| `Eye_Closed_L` / `Eye_Closed_R` | **闭眼状态**，用于眨眼。画成一条下弯的弧线睫毛即可，颜色取现有睫毛色 |
| `Mouth_Open` | **张嘴状态**，用于口型。在 `Mouth_Closed` 基础上把口型拉开，露出深色口腔 |
| `Brow_L` / `Brow_R` | **眉毛**。原图眉毛与白发同色几乎不可辨，建议新画一对淡色眉毛，用于表情 |

### 4.3 需人工优化的自动结果

| 图层 | 问题 | 处理建议 |
|---|---|---|
| `Hair_Front` | 与 `Hair_Back` 是水平直切 | 按发束重新描边，分出 2–3 束便于做摆动 |
| `Cape_Front` / `Body` | 交界处是矩形硬边 | 按披风实际下摆重新勾勒 |
| `Arm_L` / `Cape_Back` | 举臂与内衬重叠 | 确认遮挡关系，手臂应在披风之上 |
| 全部图层 | 部件内部边界是硬边（无羽化） | Cubism 中可用「自动生成网格」+ 蒙版柔化，或手工修边 |

```
assets/live2d/paimon/layers/
├── Body.png              ├── Cape_Back.png      ├── Cape_Front.png

├── Face.png              ├── Eye_L.png          ├── Eye_R.png

├── Arm_L.png             ├── Arm_R.png
├── Hand_L.png            ├── Hand_R.png
├── Leg_L.png             ├── Leg_R.png
├── Boot_L.png            ├── Boot_R.png
├── _contact_sheet.png    # 各图层预览（棋盘底）
├── _rebuild.png          # 按图层重建图，应与源图一致
├── _uncovered.png        # 未覆盖像素分布（用于排查漏切）
└── _report.txt           # 覆盖率统计
```

复现 / 调整参数后重跑：

```bash
python3 scripts/live2d/segment.py
```

脚本顶部的 `BOX` 字典与 `AHOGE_Y / HEAD_BOTTOM / FRINGE_*` 常量就是全部可调参数，
按需微调包围盒即可重新切分。

> **未输出 PSD**：本环境无 Photoshop，脚本输出的是**等价的分层透明 PNG 序列**
> （每层与源图同尺寸、同坐标，可直接在 PS 中「文件 → 脚本 → 将文件载入堆栈」合成 PSD）。
> 若需要真正的 `.psd`，可用 `psd-tools` 或在上句流程中另存。
